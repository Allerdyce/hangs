# Hangs

Responsive launch landing page for Hangs. Plain HTML, CSS, and JavaScript, with optimized app screenshots extracted from the supplied Figma exports.

## Preview

Run `python3 -m http.server 4389 --directory dist` and open http://localhost:4389.

## Product facts

- Launch: University of Minnesota, 2026; exact date not announced.
- Pricing: always free.
- No identity-verification claim for MVP.
- CTA currently opens launch information. Connect a real signup destination before opening the waitlist; no email is collected or silently stored.
- Screens and event examples are previews, not live availability.
